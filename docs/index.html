Read Markdown like a book.

Marked is a reading-first Markdown app for iOS. Open any .md file from Files or iCloud Drive and read it with classic typography, justified text and three book-style themes — with a built-in editor for quick changes.

Features

Designed to be read, not just rendered.

Every detail — typography, spacing, themes, navigation — is tuned for long-form reading. The editor stays out of the way until you need it.

¶

Book-like typography

Nine curated typefaces (New York, Georgia, Palatino, Iowan Old Style, Charter and more), justified text with automatic hyphenation, and adjustable size, line spacing and margins.

☀︎

Three reading themes

Light, Sepia and Dark — chosen for comfortable reading at any time of day, not just to flip colours.

‹›

Syntax highlighting

Code blocks are highlighted with automatic language detection. The editor colours Markdown markup live, without leaving plain text behind.

≡

Table of contents & search

Auto-generated TOC from your headings. In-document search — per section in reader mode, per line in the editor — to jump straight where you need.

✎

Built-in editor

Plain-text editing that saves back to the original file. New documents open straight into the editor. Debounced highlighting keeps large files responsive.

⏱

Fast and smooth

Documents open asynchronously. Theme and font changes reuse the parsed document instead of rebuilding it, so the UI never blocks.

❝

Styled blockquotes & tables

Quotes with accent bar, soft tint and a decorative glyph. Wrap-first tables fit your screen and only scroll horizontally as a last resort.

⌖

Recents with progress

Files are remembered with security-scoped bookmarks. Reading position is saved per document, so you continue exactly where you left off.

⌘

Works with your files

Opens .md, .markdown, .mdown and .mkd from Files, iCloud Drive and "Open with…". Create new documents from inside the app.

Reading themes

The same text, three moods.

Pick the theme that matches the light around you. Each one is paired with a serif typeface, generous margins and justified text — so the page feels like a page, not a screen.

Privacy

Your files. Your device. That's it.

Marked has no servers, no accounts and no analytics. It reads files you open and remembers where you left off — and that is all.

Read the full privacy policy →

  • Runs entirely on your device.
  • No network connections.
  • No accounts, no telemetry, no advertising, no tracking.
  • Your files stay where you keep them — Marked only opens them.
